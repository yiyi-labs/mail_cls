# 本地演示输入

以下是 Codex 为检查交互而编写的合成内容，不来自真实邮箱，也不属于 TREC06C。用途是练习粘贴输入和观察解析/模型分数，不计算准确率，不证明现代邮箱泛化。

## 课程通知场景

主题：课程项目答疑时间

正文：同学们好，本周四下午安排课程项目答疑。请准备好数据分析代码、实验记录和问题，按课程群中已确认的时间参加。如无法到场，请先联系助教说明情况。

## 未经请求的营销场景

主题：限时优惠推广

正文：您好！本公司现推出限时优惠服务，批量订购可享额外折扣。如有采购需求，请回复邮件咨询套餐和报价。此邮件为未经请求的推广演示文本。

页面里的二分类结果取决于实际模型；即使结果与场景意图不同，也应照实展示。上传 .eml 时请选择本机测试文件；程序会提取可见内容，不执行附件或脚本。

## 上传演示文件

在项目根目录执行 `.venv/Scripts/python.exe examples/make_demo_emails.py`，生成本目录的 `course_notice.eml` 与 `marketing_demo.eml`。两者均采用合法 UTF-8/Base64 包装，收发地址使用不可投递的 example.invalid，包含合成来源标记。当前工作区已生成，可直接在页面选择“上传单封 .eml”使用。它们不参与训练或正式测试；生成脚本可维护，`.eml` 按项目规则默认忽略。
